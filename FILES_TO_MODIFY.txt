COMPILATION ISSUES TO WATCH FOR
═══════════════════════════════════════════════════════════════════════════════

GCC 15.1.0 Warnings (Will fail as errors):
- Unterminated string initialization: char arr[3] = "foo" (need arr[4])
- Dangling references: const int& ref = std::max(a, b)
- Dirent header: Use <dirent.h> not <sys/dirent.h>

Solution: 
1. Fix the warnings in source code (PREFERRED)
2. Or disable in sdkconfig:
   CONFIG_COMPILER_DISABLE_DEFAULT_ERRORS=y
   CONFIG_COMPILER_DISABLE_GCC15_WARNINGS=y
